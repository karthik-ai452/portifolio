# Portfolio

This repository contains the source code for my portfolio website. It showcases my projects, skills, and experience.

Access at: https://portifolio1-henna-eight.vercel.app/

## Files

- **index.html**: The main HTML file for the portfolio.
- **app.css**: Stylesheet for the portfolio.
- **main.js**: JavaScript file for interactivity.
- **karthik_portfolio_3d_light.html**: Additional HTML file for 3D light effects.
- **styles.css**: Additional styles.

## How to View

1. Clone the repository:
   ```
   git clone https://github.com/karthik-ai452/portifolio.git
   ```
2. Navigate to the folder:
   ```
   cd portifolio
   ```
3. Start a local server:
   ```
   python -m http.server
   ```
4. Open your browser and go to:
   [http://localhost:8000](http://localhost:8000)
